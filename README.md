# เช็คเงินตัดแอด Meta (NISIT BillCheck)

โปรแกรมสำหรับทีมแอดของ NISIT ดูว่าบัญชีโฆษณาไหนตัดเงิน โหลดบิลจาก Meta แล้วจับคู่กับ SMS เงินออกของธนาคาร ผลตรวจส่งขึ้นระบบ NISIT เอง ฝ่ายบัญชีดูที่หน้าเติมงบแอด แท็บเช็คเงินตัด

## ติดตั้ง

1. ดาวน์โหลด [ZIP](https://github.com/Khomkrich97/setto-billcheck/archive/refs/heads/main.zip) แล้วแตกไฟล์ทั้งโฟลเดอร์
2. ดับเบิลคลิก `START.bat` ครั้งแรกติดตั้ง Python และเครื่องมือเอง ประมาณ 5 ถึง 10 นาที
3. ล็อกอินด้วยอีเมลและรหัสระบบ NISIT แล้วกด เริ่มตรวจ ครั้งแรกล็อกอิน Facebook ของตัวเองในหน้าต่างที่เด้งขึ้นมา

วิธีใช้ทั้งหมดอยู่ใน `อ่านก่อน.txt`

## อัปเดต

ทุกครั้งที่เปิด โปรแกรมเทียบ `app/VERSION` กับ GitHub ถ้าต่างกันจะโหลดโฟลเดอร์ `app/` ชุดใหม่มาเปลี่ยนเองแล้วเปิดใหม่

ปล่อยเวอร์ชันใหม่: แก้โค้ด เปลี่ยนเลขใน `app/VERSION` แล้ว push ขึ้น `main`
เปลี่ยน library ให้แก้บรรทัด `DEPS` ใน `START.bat` เครื่องของทีมจะติดตั้งให้เองก่อนเปลี่ยนเวอร์ชัน
โฟลเดอร์ที่เป็น git clone ไม่อัปเดตตัวเอง (`START.bat` ตั้ง `BILLCHECK_NO_UPDATE`) ใช้ทดสอบก่อน push

## ข้อมูลอยู่ที่ไหน

`%LOCALAPPDATA%\NISIT\billcheck` เก็บตัวโปรแกรมที่ติดตั้ง การล็อกอินที่เข้ารหัสด้วย Windows โปรไฟล์ Facebook ของโปรแกรม PDF บิล 30 วัน และ `app.log`

โปรแกรมไม่กดจ่ายเงินใดๆ ใน Facebook กดแค่ปุ่มดาวน์โหลดบิล
